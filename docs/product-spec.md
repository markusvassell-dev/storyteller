# Product specification

## What it is

**Storytime Library** is a private digital bookshelf for one household: a
warm, calm place to collect and read children's picture books on iPhone and
iPad, installable from Safari as a Home Screen web app.

One person (the owner) curates the collection through a PIN-gated workshop;
children only ever see the reading experience.

## Core experiences

### Library home
A bookshelf with large covers on horizontal shelf rows: Continue Reading,
Favourites, Recently Added, category shelves (Robert Munsch Collection, Fairy
Tales, Brothers Grimm, Folk Tales, Bedtime Stories, Short Reads,
Public-Domain Classics, and more), and My Imported Books. Typo-tolerant
search and filters (author, category, age range, reading level, length,
narration availability, imported/built-in, favourites). Friendly empty states.

### Book details
Cover, title/subtitle, author/illustrator/translator, description, age range,
estimated time, page count, narration availability, offline status, Read /
Resume / Start over, favourite toggle, and a collapsible "About this book's
source & rights" panel — rights info is available without making reading feel
legalistic. Owners additionally see an Edit button when unlocked.

### Reader
Immersive page-by-page picture-book reading:

- portrait & landscape; single page on phones, optional two-page spread on
  tablet-sized screens (cover alone, then pairs, like a paper book)
- artwork never cropped by default (letterboxed `contain`); optional `cover`
  fit with a configurable focal point per page
- visible Previous/Next buttons, optional swipe, 300 ms tap debounce
- page number + progress bar; automatic progress save and resume
- distraction-free mode (controls tuck away; a restore button remains)
- text-size steps, reduced-motion toggle, subtle page transitions
- full keyboard support and screen-reader announcements

### Narration
Prerecorded audio (per-page files or one whole-book recording with per-page
timestamps) with play/pause, replay page, speed, volume, mute, captions and
optional automatic page turns; plus device text-to-speech with voice and
speed selection, clearly labelled as generated by the device. Narration never
autoplays — it starts from a tap. Books without audio fall back to TTS; if
the device has no TTS, the reader simply reads silently.

### Owner workshop
Add / edit / duplicate / delete / hide / reorder books, manage categories,
storage screen, integrity check, and an 8-step add-book wizard (files →
details → page order → page text → narration → rights → preview → save)
supporting PDF, images, ZIP/CBZ, audio, and story packages. Validation
blocks malformed books; unclear rights quarantine the book.

### Backup & restore
One-file export of the private library (optionally password-encrypted),
restore on any device — the supported iPhone ↔ iPad transfer path.

## Principles

- **Local-first & private**: private books, history and settings live on the
  device. The public host serves only the app shell and verified demo books.
- **Rights-honest**: every book carries provenance; builds fail if private or
  undocumented content would ship.
- **Calm design**: cozy nighttime-library identity, generous type, soft
  motion, bedtime-friendly dark theme; no gamification, no notifications.
- **Accessible**: WCAG 2.2 AA target; no gesture-only actions; alt text is
  mandatory in the data model.
- **Free to run**: static hosting on a free tier; no accounts or paid
  services.

## Out of scope (initial version)

Multi-language UI (data model keeps `language: "en"` for the future), cloud
sync, OCR, App Store distribution, multi-user profiles.
